## Herramientas

- **Odoo** — ERP-CRM libre utilizado para las prácticas de instalación, configuración y adaptación
- **Python** — lenguaje de programación incorporado para el desarrollo de componentes
- **PostgreSQL** — sistema gestor de datos del ERP-CRM
